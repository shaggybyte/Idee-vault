# Granice nieprzewidywalności — materiał projektu

> [!info] Podstawa opracowania
> Odczytano kluczowe sekcje HTML `granice.html`, w tym mapę pojęć, rozróżnienie chaos/krytyczność, karty dowodów i bibliografię. Plik zawiera również osadzone dane graficzne, których nie analizowano piksel po pikselu.

## Główna teza

„Chaos nie jest przypadkiem. Niepewność nie jest nieoznaczonością.” Materiał dzieli granice predykcji na:

1. **epistemiczną** — brak wiedzy o stanie/modelu;
2. **dynamiczną** — wzmacnianie małych różnic przez dynamikę;
3. **ontologiczną** — probabilistyczny charakter wyniku na poziomie teorii fundamentalnej.

Problem trzech ciał jest używany jako przykład **nieprzewidywalności bez indeterminizmu**.

## Mózg

Materiał podkreśla, że mikroskopijna perturbacja musi zostać odpowiednio wzmocniona, by zmienić makroskopowy rezultat. Rozróżnia także:

- chaos deterministyczny,
- krytyczność,
- szum kanałowy/synaptyczny,
- niestacjonarność i wejścia stabilizujące.
