# Via negativa

*Via negativa* to strategia poprawy przez **usuwanie** szkodliwych elementów zamiast automatycznego dodawania nowych interwencji.

## SOURCE CLAIM — Taleb

W *Antykruchości* Taleb łączy ją z asymetrią wiedzy: często łatwiej jest rozpoznać coś szkodliwego niż dowieść, że nowy złożony dodatek przyniesie netto korzyść bez nieznanych efektów ubocznych.

## Najważniejsze rozróżnienie

Via negativa nie jest zasadą „nic nie rób”. Jest heurystyką szczególnie atrakcyjną, gdy:

- system jest złożony,
- skutki uboczne są trudne do przewidzenia,
- istnieje kumulacja interwencji,
- usunięcie ekspozycji ma dobrze określony downside.
