# System 1 i System 2

## Model

W *Pułapkach myślenia* Kahneman używa dwóch „aktorów” jako narzędzia wyjaśniającego:

- **System 1** — szybki, automatyczny, mało wysiłkowy, generuje skojarzenia i intuicyjne odpowiedzi;
- **System 2** — wolniejszy, wysiłkowy, związany z uwagą, kontrolą i obliczeniem.

> [!important]
> To model funkcjonalny i narracyjny, nie twierdzenie o dwóch anatomicznie odrębnych „mózgach”. Sam Kahneman przedstawia systemy jako wygodne postacie w psychodramie opisu poznania.

## Znaczenie

System 1 pozwala działać sprawnie w ogromnej liczbie codziennych sytuacji, ale jego automatyczne reguły mogą generować przewidywalne błędy. System 2 może je czasem korygować, lecz jest kosztowny uwagowo i nie monitoruje wszystkiego.
