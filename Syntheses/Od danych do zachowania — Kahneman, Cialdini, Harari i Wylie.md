# Od danych do zachowania — Kahneman, Cialdini, Harari i Wylie

## SYNTHESIS

Cztery źródła opisują różne warstwy jednego procesu:

1. **[[Pułapki myślenia — Daniel Kahneman|Kahneman]]** — osąd korzysta z automatycznych skrótów i jest częściowo nieprzezroczysty dla introspekcji;
2. **[[Wywieranie wpływu na ludzi — Robert Cialdini|Cialdini]]** — bodźce społeczne mogą uruchamiać zwykle użyteczne reguły uproszczone;
3. **[[21 lekcji na XXI wiek — Yuval Noah Harari|Harari]]** — ogromne zbiory danych mogą zwiększać asymetrię między jednostką a instytucją;
4. **[[Mindfck — Christopher Wylie|Wylie]]** — opisuje praktyczny stos: dane → model → segment → dopasowany przekaz → platforma dystrybucji.

## Minimalny model

`ślady zachowania → model prawdopodobieństwa → segmentacja → wybór bodźca/narracji → ekspozycja → reakcja → nowe dane`

## Najważniejszy wniosek

System **nie musi znać człowieka lepiej niż on sam w każdym sensie**, aby uzyskać przewagę. Wystarczy, że:
- w określonym zadaniu posiada więcej danych,
- lepiej szacuje rozkład reakcji,
- może testować wiele wariantów,
- kontroluje moment i kanał ekspozycji.

To jest słabsza teza niż „algorytm zna twoje prawdziwe ja”, ale bardziej użyteczna analitycznie.

## Granice

- korelacyjny profil nie jest pełnym modelem osoby;
- predykcja nie jest perswazją;
- perswazja nie jest kontrolą;
- efekt populacyjny nie przesądza reakcji jednostki;
- relacja Wyliego nie sama w sobie dowodzi wielkości efektu wyborczego.
