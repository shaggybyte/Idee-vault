# README

Vault jest rozwijaną bazą wiedzy projektu **Idee**. Nie zawiera kopii pełnych książek ani pełnych transkrypcji. Zawiera notatki źródłowe z jawnym zakresem dostępu, notatki kanoniczne, mapy sporów i syntezy.

## Główna zasada

**Źródło nie jest właścicielem prawdy.** Autor lub rozmówca może być źródłem tezy; notatka kanoniczna ma zachować możliwość jej porównania z innymi źródłami, kontrargumentami i późniejszą wiedzą.

## Architektura

- `Concepts/` — pojęcia wielokrotnego użytku.
- `Debates/` — pytania, dla których istnieją konkurencyjne stanowiska lub ważne rozróżnienia.
- `Syntheses/` — jawnie autorskie syntezy łączące wiele źródeł.
- `Sources/Books/` — książki i monografie.
- `Sources/YouTube/` — **oddzielny** korpus filmów, wykładów, podcastów i transkrypcji; mapa: [[YouTube źródła MOC]].
- `Sources/External/` — publikacje i zewnętrzne materiały używane do weryfikacji.
- `Sources/Project/` — materiały powstałe w projekcie.
- `Thinkers/` — indeksy dorobku autorów, nie silosy treści.
- `MOCs/` — mapy nawigacyjne.
- `_Meta/` — standardy, wersje, audyty i raport importu.

## Hierarchia źródłowa

Typ źródła jest widoczny i ma znaczenie. Wykład eksperta może być świetnym źródłem mapy problemu lub stanowiska, ale ważne techniczne twierdzenie empiryczne z YouTube powinno — gdy to możliwe — prowadzić dalej do publikacji pierwotnej. Automatyczna transkrypcja jest warstwą dostępu, nie gwarancją poprawności terminologii.
