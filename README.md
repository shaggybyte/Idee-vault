# README

Vault powstał jako pierwsza wersja rozwijanej bazy wiedzy projektu **Idee**. Nie zawiera kopii pełnych książek. Zawiera za to notatki źródłowe z jawnym zakresem dostępu, notatki kanoniczne, mapy sporów i syntezy.

## Główna zasada

**Źródło nie jest właścicielem prawdy.** Autor może być źródłem tezy; notatka kanoniczna ma zachować możliwość jej porównania z innymi źródłami, kontrargumentami i późniejszą wiedzą.

## Architektura

- `Concepts/` — pojęcia wielokrotnego użytku.
- `Debates/` — pytania, dla których istnieją konkurencyjne stanowiska lub ważne rozróżnienia.
- `Syntheses/` — jawnie autorskie syntezy łączące wiele źródeł.
- `Sources/` — książki, materiały projektu i zewnętrzne publikacje.
- `Thinkers/` — indeksy dorobku autorów, nie silosy treści.
- `MOCs/` — mapy nawigacyjne.
- `_Meta/` — standardy, wersje, audyty i raport importu.
