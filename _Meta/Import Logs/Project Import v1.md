# Project Import v1

## Materiały pełnotekstowe

- *Antykruchość* — EPUB
- *Zdeterminowany* — MOBI
- *Pułapki myślenia* — MOBI
- *Niepowstrzymani* — MOBI
- *21 lekcji na XXI wiek* — PDF
- *Otoczeni przez idiotów* — MOBI
- *Wywieranie wpływu na ludzi* — EPUB
- *Człowiek. Biografia* — PDF

Pełna warstwa tekstowa została odczytana/wyodrębniona. W przypadku MOBI/EPUB nie oznacza to pełnego audytu ilustracji i układu stron.

## Materiały projektu

- rozmowy projektu — dostęp częściowy, nie pełny eksport transcriptów;
- `granice.html` — kluczowa treść i bibliografia odczytane;
- `ewolucja_czlowieka_semantic_graph.json` — pełny JSON;
- grafiki drzewa homininów — odczyt wizualny/opisy dostępne w Bibliotece.

## Zewnętrzna weryfikacja

Dla problemu „wielkiego rozłamu” australopiteków sprawdzono bieżące artykuły *Nature* / *Nature Communications* o Ledi-Geraru, morfologii *H. habilis* i złożonym pojawieniu się *H. erectus*. Nie wykonywano analogicznego przeglądu aktualnej literatury dla każdego pojęcia z każdej książki — taki zakres byłby osobnym projektem.

## Ograniczenie

Vault v1 jest **integracją projektu i dostępnej literatury**, nie próbą stworzenia kompletnej encyklopedii wszystkich ośmiu książek. Priorytetem były idee faktycznie aktywne w rozmowach projektu i węzły, które będą użyteczne przy dalszej rozbudowie.
